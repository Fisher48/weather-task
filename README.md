# weather-task

Скрипт на Python, который загружает список городов из файла, получает по каждому городу текущую погоду через [wttr.in](https://wttr.in) и печатает отчёт: данные по городам и сводку по странам.

## Возможности

- Список городов читается из `cities.txt` в память; пустые строки и дубликаты (без учёта регистра) отбрасываются.
- Для каждого города запрашивается `https://wttr.in/{City}?format=j1`.
- Данные складываются в модель `WeatherData`: город, текущая температура в °C, страна.
- Вывод по каждому городу: `City, Country +18°C`.
- Группировка по странам: количество городов, средняя, минимальная и максимальная температура.

## Зависимости

Только стандартная библиотека Python 3.9+ (`urllib.request`, `json`, `dataclasses`, `collections`). Сторонние пакеты не требуются.

## Запуск

```bash
python3 weather.py
```

Город задаётся списком в `cities.txt`, по одному в строке:

```
Moscow
Khabarovsk
Saint-Petersburg
...
```

## Пример вывода

```
Погода по городам:
Moscow, Russia +13°C
Khabarovsk, Russia +8°C
Vienna, Austria +21°C

Сводка по странам:
Austria - 2 cities, avg: +12°C, min: +4°C, max: +21°C
Russia - 5 cities, avg: +8°C, min: +2°C, max: +13°C
```

## Детали реализации

- Между запросами делается пауза, так как wttr.in ограничивает частоту обращений.
- Сетевые ошибки и неизвестные города обрабатываются: запрос повторяется до трёх раз, при неудаче город пропускается с сообщением в `stderr`, агрегаты считаются по успешным ответам.
- Название города в выводе берётся из входного файла, а не из ответа API: wttr.in возвращает локализованные имена (например, `Москва`).
